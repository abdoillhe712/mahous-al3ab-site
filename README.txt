# مهوس الألعاب

نسخة أولية لموقع عربي لعرض سكريبت ماب البيضة لروبلوكس.

## الملفات
- `index.html` الصفحة الرئيسية
- `download.html` صفحة الحصول على السكريبت
- `style.css` التصميم
- `script.js` التفاعل البسيط

## قبل النشر
1. استبدل رابط `#` في `download.html` برابط الملف الحقيقي.
2. استبدل مساحات "مساحة إعلانية" بكود شبكة الإعلانات بعد قبول الموقع في الشبكة.
3. أضف صفحات الخصوصية وشروط الاستخدام وبيانات التواصل.
4. تأكد أن السكريبت مسموح به في اللعبة ولا يخالف شروطها.
